# BearBrowser Branding

BearBrowser uses its own product identity.

## Product-facing name

Use:

```text
BearBrowser
```

Do not ship user-facing builds that say LibreWolf in browser chrome, app menus, desktop entries, dock entries, profiles, icons, appstream metadata, package names, or generated build artifacts.

## Upstream attribution

LibreWolf references are allowed only in upstream provenance, build metadata, documentation, and license/attribution contexts. Do not remove required license notices.

## Assets

- `branding/bearbrowser.svg` — canonical BearBrowser SVG icon.

## Overlay

`scripts/apply-bearbrowser-branding.sh` applies branding to generated workspaces after the LibreWolf-derived source overlay is created.
